How it works

  1. Merchant creates an invoice (amount, payer, memo, expiry) and shares the link.
  2. Payer approves exactly the invoice amount in tUSD8, then pays — funds go into escrow in the contract.
  3. Merchant clicks Settle to withdraw the tUSD8 to their wallet — minus the 0.5% protocol fee, which goes to the protocol fee recipient (visible in the explorer). Refunds are always fee-free and return the full amount.
  4. Agents (v2): a merchant approves an agent with a spending cap and expiry; the agent pays invoices within the cap; the merchant can revoke anytime. Settled invoices paid by a registered agent grow that agent's on-chain reputation in the AgentRegistry.
  5. If the invoice expires unpaid, it can no longer be paid. If it is paid but the merchant never settles within 7 days, the payer can Refund in full.
  6. No protocol fee, no owner, no admin, no backend. Every state change is on-chain and verifiable in the explorer.
